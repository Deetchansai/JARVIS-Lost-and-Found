# Campus Lost and Found - Frontend Web Client

The React-based single page application for the Campus Lost and Found platform.

## Features
- **Item Discovery**: Feed of campus lost and found items with real-time text and category filters.
- **Reporting Flow**: Multi-field forms for lost and found reports with location and image attachments.
- **AI Matching Tracker**: History dashboard comparing reported items against candidates with AI confidence breakdown.
- **Alert Drawer**: In-app notification bell indicating potential item pairings.

## Available Scripts

### `npm install`
Installs all project dependencies.

### `npm start`
Runs the client in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder.
